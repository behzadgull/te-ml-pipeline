# paper/

- `paper/paper.md` is the source of truth. `paper.docx` is a generated
  export for the supervisor, never hand-edited — regenerating it from
  `paper.md` overwrites it. (Converted from a LaTeX skeleton on
  2026-09-14: no LaTeX toolchain is available on this machine, so
  Markdown stays the tracked source and Word is produced as an export
  instead of authored directly.)
- Every number in the text must cite the `results/`, `checkpoints/`, or
  `reports/` artifact it came from — same standing rule as CLAUDE.md.
- Figures are generated by `scripts/make_figures.py` and copied into
  `paper/figures/`, never edited by hand.
- The canonical dataset is File A, sha256
  `e97406fa5223efa466d1e3fe4ffb2b1bc0303dc94b6adac6a824a643a9156f8d`; no
  number in the paper may derive from File B without being labelled as
  such.
